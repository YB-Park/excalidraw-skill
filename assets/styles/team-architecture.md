# team-architecture

Professional default style for software architecture diagrams.

The renderer owns exact visual values. The agent should only reference this preset by name.

## Layout tokens

- grid: medium
- rank gap: wide
- node gap: comfortable
- frame padding: generous

## Visual tokens

- roughness: low sketch
- stroke width: medium
- label size: readable
- edge label size: compact

## Palette roles

- default node
- primary service
- data store
- external system
- async component
- risk or warning
- frame background

## Rules

- Use color for meaning, not decoration.
- Avoid more than three strong color roles in one diagram.
- Keep frames subtle.
- Keep service labels short.
- Prefer whitespace over dense packing.
