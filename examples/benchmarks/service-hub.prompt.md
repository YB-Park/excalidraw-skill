# Service Hub Benchmark

Create an editable Excalidraw architecture diagram with `Notification Service` as the central service.

Connected systems:

- Order Service
- Billing Service
- User Service
- Email Provider
- SMS Provider
- Push Provider
- Notification DB
- Notification Queue

Requirements:

- use a hub-and-spoke visual structure
- keep internal services visually separate from external providers
- place data and queue components near Notification Service without obscuring the main relationships
- use professional-software style and semantic ids
- avoid label overlap and unnecessary edge crossings
