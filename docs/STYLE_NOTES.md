# Style Notes

Default visual target: professional, readable, and easy to edit.

Core rules:

- Use short labels.
- Keep primary nodes under nine when possible.
- Prefer left-to-right service flow diagrams.
- Keep enough space between nodes and edge labels.
- Avoid icon overload.
- Preserve manual layout when modifying existing diagrams.

These notes are intentionally lightweight. The concrete style preset will be added after the renderer stabilizes.
